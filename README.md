# Site académique — Pr. Aïssa Sghir

Première version du site personnel, centrée sur la pédagogie et la recherche. Contenu issu du CV fourni le 10 novembre 2026. Les supports pédagogiques et références complètes des articles restent à ajouter. Aucun portrait, lien de cours ou titre d’article n’a été inventé.

## Consulter localement

Ouvrir `index.html` dans un navigateur, ou lancer `node server.cjs`, puis consulter http://localhost:3000.

## Modifier le site

- `index.html` : profil, recherche, encadrements, contact.
- `script.js` : catalogue des enseignements et filtres.
- `style.css` : présentation et adaptation mobile.
- `favicon.svg` : icône du site.

Les dates et situations des encadrements reflètent le CV et sont à actualiser au besoin. Les regroupements d’enseignements sont destinés à cette première présentation.

## GitHub et Vercel

Le site est statique et ne nécessite aucune installation de dépendances ni compilation. Publier les sources dans un dépôt GitHub puis importer ce dépôt dans Vercel avec le préréglage **Other**, sans commande de compilation et avec le dossier de sortie `.`. La configuration est fournie dans `vercel.json`.

Les mises à jour de la branche reliée au projet Vercel permettront de conserver le même lien tout en complétant le site.
